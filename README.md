# AEGILAB 🔐

## Mini SOC + Red Team Lab

AEGILAB is a hands-on cybersecurity lab I am building from the ground up to practise offensive security, detection, investigation, and defensive security.

The goal is to move beyond simply learning cybersecurity concepts and put those concepts into practice in a controlled environment.

### Core Workflow

**Attack → Detect → Investigate → Defend**

### What I Plan to Practise

- Networking fundamentals
- Linux
- Reconnaissance
- Scanning and enumeration
- Attack simulation
- Log collection and analysis
- Threat detection
- Security investigation
- Defensive response

### Planned Lab Components

- Attacker machine
- Target machine
- Network environment
- Logging and monitoring
- Detection and analysis tools
